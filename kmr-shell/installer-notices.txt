SECURITY NOTICE - PLEASE READ
-----------------------------
* This installer is NOT code-signed. Microsoft Defender SmartScreen may show
  "Windows protected your PC". Only continue if you downloaded this installer
  from the official GitHub release page and its SHA-256 checksum matches the
  one published there:
  https://github.com/TheImortalimp/K-Meleon-R/releases
* With ADMINISTRATOR rights (UAC) the installer applies Windows
  pointer/theme/sound policy hardening across local profiles (anti GEM OS /
  cursor-theft defenses). Uninstalling the browser does NOT automatically
  restore these Windows policy changes.
* WITHOUT administrator rights the browser installs per-user and the Windows
  policy hardening steps are skipped; the hardening scripts are installed
  alongside the application and can be run elevated later.
