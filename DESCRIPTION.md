# K-Meleon-R - Description

## GitHub About

K-Meleon-R r13 (8.5.0): standalone Windows WebView2 browser with GX-style speed dial, tabs, five themes and Copilot/Gemini web shortcuts. System-pointer protection and theme/pointer package blocking.

## Summary

K-Meleon-R combines a lightweight WinForms/WebView2 browser shell with editable
speed dials, synchronized themes, browser tabs and web search/AI shortcuts.
It runs on Windows 10/11 x64 with Microsoft Edge WebView2.

r13 retains system-pointer protection, adds theme/pointer package restrictions
and sound-scheme policy, and ships elevated Windows hardening scripts.
The installer changes Windows settings; it is unsigned, quarantine is opt-in,
and these targeted defenses are not a general safety guarantee.
