# K-Meleon-R - Description

## GitHub About

K-Meleon-R r15 (8.7.0) - latest query-search and general bug-fix release. Windows x64 WebView2 browser with synchronized Gemini/Copilot search, full-query routing, private tabs and GX-style themes. EXE installer and portable ZIP.

## Summary

K-Meleon-R combines a lightweight WinForms/WebView2 browser shell with editable
speed dials, synchronized themes, browser tabs, private tabs and web search/AI
shortcuts. It runs on Windows 10/11 x64 with Microsoft Edge WebView2.

**r15 (8.7.0), released 2 November 2026, is the current release**, superseding
r14 and earlier builds. This query-search fix and general bug-fix build
completes Gemini (Google AI Mode)/Copilot Search query routing, synchronizes
the selected provider between toolbar and start page, and preserves full
submitted queries without sharing typing or sending searches to both services.
Website addresses still open normally. Additional fixes preserve unfinished
address-bar input and private Ask tabs and correct portable-package contents.
Since r14 the browser integrates SmartScreen, attachment-service/AMSI download scanning through
the installed antivirus, a Security Center watchdog, optional Google Safe
Browsing lookups, an anti-screencap window shield and a script-scheme phishing
filter, on top of the r12/r13 theme/cursor takeover defenses.
The installer changes Windows settings; it is unsigned, quarantine is opt-in,
and these layered defenses are not a general safety guarantee.
